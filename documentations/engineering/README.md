# Engineering Reference

Start with [the repository roadmap](../../ROADMAP.md) and the work-item specifications in `work-items/`.

This documentation is an initial engineering import. Issue bodies and PR discussions become the execution record after deployment; the import tool never overwrites later human refinement. The JSON manifest is the reviewed baseline, not a continuous state synchronization service.

The package baseline is September 21, 2026. The original preparation session was denied GitHub write access. A later deployment must retain its actual receipt; document presence does not prove native metadata or product qualification.

Read [Governance](GOVERNANCE.md), [Evidence and limits](EVIDENCE_AND_LIMITS.md), [the review-package reconciliation](ARCHIVE_RECONCILIATION.md), [the GitHub deployment receipt](GITHUB_DEPLOYMENT_RECEIPT.md), [Cross-repository sequencing](CROSS_REPOSITORY_SEQUENCE.md), and [Validation](VALIDATION_PROTOCOL.md).

SDK owns integration facts, native safety, Lua protection and resource authority. Client owns developer workflows and policy. A contract in source, a published artifact and a live-tested capability are different evidence states.
