## SDK-006 — Decide the NativeAOT plugin loader profile without weakening managed support

**Owner:** `CheatEngineNet/CheatEngine.SDK` · **Kind:** research · **Priority:** P2 · **Milestone:** SDK-M1

**Initial status:** Needs refinement. **Runtime validation:** Not executed by this bootstrap.

### Context and evidence

A standalone NativeAOT probe exists. The prior loader comparison includes FreeLibrary, while Microsoft documents that NativeAOT libraries cannot be unloaded.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.

### Outcome and rationale

Produce a loader/lifetime ADR with measured prerequisites; keep the managed plugin deployment as the baseline.
