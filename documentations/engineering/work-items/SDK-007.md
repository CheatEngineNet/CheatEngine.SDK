## SDK-007 — Preserve structured outcomes across Lua and Engine primitives

**Owner:** `CheatEngineNet/CheatEngine.SDK` · **Kind:** feature · **Priority:** P1 · **Milestone:** SDK-M2

**Initial status:** Needs refinement. **Runtime validation:** Not executed by this bootstrap.

### Context and evidence

Prior audit: generated Try helpers and the AOB bool merge missing-global, execution, nil and malformed-result causes. The allocation adapter already distinguishes more cases.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.

### Outcome and rationale

Add a compact, additive outcome vocabulary that higher layers can project without parsing text.
