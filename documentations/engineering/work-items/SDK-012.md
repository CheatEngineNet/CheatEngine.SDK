## SDK-012 — Qualify shared Lua state, reset, and protected operation boundaries

**Owner:** `CheatEngineNet/CheatEngine.SDK` · **Kind:** validation · **Priority:** P1 · **Milestone:** SDK-M2

**Initial status:** Needs refinement. **Runtime validation:** Not executed by this bootstrap.

### Context and evidence

The historical CE source creates thread-associated Lua coroutines from one VM. The SDK native bridge is an existing protection mechanism and must be preserved.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.
