## SDK-017 — Qualify Auto Assembler patch application and disable ownership

**Owner:** `CheatEngineNet/CheatEngine.SDK` · **Kind:** validation · **Priority:** P1 · **Milestone:** SDK-M4

### Context and evidence

AutoAssemblerPatcher already owns disable-info at SDK main, but target identity and the post-success owner handoff require qualification.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.

### Outcome and rationale

Make patch/disable semantics safe and factual before Client adoption.

- [ ] Root disable-info under the correct Lua universe; do not reconstruct cleanup from addresses or script text.
