#### SDK-017 implementation and qualification boundary — 2026-09-21

- `AutoAssemblerPatch.ReleaseWithTargetOutcome()` is an additive structured cleanup path. It consumes the owner before
  any Lua work and reports `Released`, an identity-based refusal, `NotInvoked` when it cannot begin cleanup, or
  `UnconfirmedAfterInvocation` only after a disable invocation can have had an effect; it does not retry, reselect a
  target, or rebuild CE cleanup data from script text or addresses.
- The deterministic native-Lua fixture injects failed owner publication, disable-info tracking, and false/raising
  compensation. It also verifies a mismatched captured target has zero disable calls, stale Lua lifecycle cleanup stays
  out of a replacement universe, and repeated release/dispose cannot replay cleanup. The targeted xUnit/MTP executable
  ran 19 Auto Assembler tests successfully; the complete Debug executable campaign ran 2,176 tests across 11 test
  executables with no failures or skips.
- .NET SDK 10.0.401 restored and built the Debug and Release solutions with analyzers enabled and no warnings/errors.
  `dotnet test` itself still returns MTP exit code 5 after discovering zero tests, even though the generated executable
  discovers and runs them; direct executable evidence is therefore recorded rather than treating the wrapper as green.
- `dotnet pack src/CheatEngine.SDK/CheatEngine.SDK.csproj -c Release --no-build --no-restore` created
  `CheatEngine.SDK.1.0.1-alpha.0.19.nupkg`. The rooted Native-AOT probe published and executed for `win-x64`; this
  verifies trim/AOT diagnostics and its representative managed paths, not Cheat Engine plugin hosting.
- No installed Cheat Engine host was launched, selected, or mutated. In particular, an A→B target change in one Lua
  generation, exact original-byte restoration, and live disable/re-enable remain pending. The ambient target
  observation-to-effect interval is explicitly not an atomic CE target lock, and arbitrary Auto Assembler remains an
  expert capability rather than a sandbox or Client adoption approval.
