### SDK-018 implementation evidence

The internal classic dispatcher installs an AOT-safe static `stdcall` thunk and roots its managed handler before the
host registration call. Its callback makes one synchronous, constrained decision, but the unqualified profile always
returns `0`: a request to own continuation is observed and rejected rather than invoking the source-indexed-only
`ContinueDebugEvent` pointer cell. Observations are scalar copies placed in a bounded, lossy telemetry buffer after
admission; neither a buffer reader nor asynchronous work controls the native return.

Teardown closes admission before unregistering, waits for callbacks admitted before that close, and releases the
native record and managed root only after unregister succeeds. A failed or throwing unregister leaves the root and
record intact for a conservative retry. Releasing from the callback is refused to avoid classic host-lock reentrancy.
The fixture suite validates these paths using a simulated stdcall host. It is not evidence that the CE 7.7 runtime
table or debugger continuation path is qualified; a future live canary must establish that separately.
