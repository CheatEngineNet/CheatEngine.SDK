## SDK-019 — Qualify timer and hotkey subscription ownership

**Owner:** `CheatEngineNet/CheatEngine.SDK` · **Kind:** research · **Priority:** P2 · **Milestone:** SDK-M5

**Initial status:** Needs refinement. **Runtime validation:** Not executed by this bootstrap.

### Context and evidence

Client timer/hotkey contracts remain unavailable. Host subscriptions require rooted callbacks, teardown and runtime-generation contracts.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.

### Outcome and rationale

Provide SDK-owned subscription primitives only for qualified host behavior.

**Expected benefit:** Provide SDK-owned subscription primitives only for qualified host behavior.

### Architectural responsibility

SDK owns CE mappings, native safety, factual outcomes and low-level owners. Client owns application policy, typed workflows, composition, and developer experience.

### Technical requirements and task checklist

- [ ] Define registration failure, callback affinity, exception containment and single-use unregister.
- [ ] Neutralize callbacks before plugin-managed state is destroyed.
- [ ] Keep application scheduling policy and stream delivery outside SDK.

### Acceptance criteria

- [ ] A callback cannot enter an expired activation.
- [ ] Repeated teardown does not call freed native state.
- [ ] Copied event payloads do not expose borrowed host pointers.

### Required validation

- [ ] Registration failure, callback racing disable and re-enable fixtures.
- [ ] Live host timer/hotkey teardown profile.

### Scope exclusions

- Keep integration mechanisms in SDK and application policy/workflows in Client.
