  `ILuaMarshaller<T>` for both a Lua global and generated callback. It asserts deterministic markers for the
  marshalling round trip, rejection/replacement/restoration lease semantics, and factual
  `LuaOperationStatusKind.LuaFailure` plus `LuaStatus.RuntimeError`. A separate package-only source intentionally
  fails with `CESDK2005`; the fixture also retains the minimal plugin, relay and historical `AobScanner.TryScan`
  consumer checks.
- The checked-in Lua 5.3 DLL is an offline test fixture supplied explicitly to that executable. It is not a Cheat
  Engine host and this work does not claim a live Cheat Engine load, execution or qualification. Similarly, the
  trimmed self-contained `win-x64` Native AOT executable is published and run separately; that proves standalone
  package-consumer publication only, not Cheat Engine plugin loading, hosting or unloading.
